#  Gratitude App

A simple evening reflection app designed to help you pause before the day ends and record **three good things** you’re grateful for.  
This project combines a calming interface with inspirational quotes and a history of past reflections to encourage daily mindfulness.

---

##  Features
- **Daily Gratitude Entries**: Write down three things you’re grateful for each day.
- **Tiny Wins**: Capture one small step toward the life you want.
- **Date Navigation**: Move between days, jump back to today, or pick a date.
- **Inspirational Quotes**: Refresh motivational quotes for encouragement.
- **History Tracking**: View past reflections and track streaks.
- **Accessible Design**: ARIA labels, semantic HTML, and responsive layout.
- **Visual Atmosphere**: Animated starry background for a calming experience.
